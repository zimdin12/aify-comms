## Decisions (reversible)

- **Everything low-risk is fixed.** Backlog only what needs a design or an operator decision.
- **Four slices, no shared files:** service+bridge+installer (tech lead, main checkout); dashboard
  (subagent, worktree); skills+docs+tool text (subagent, worktree); aify-env+aify-wrapper (subagent,
  worktree). Each fix is shown red without it, restored by copy, and committed per subject.
- **Versions:** aify-comms and aify-env go to 0.7.1; aify-wrapper gets a new pinned sha.
- **Nothing is deployed.** Deploy stays the operator's.
