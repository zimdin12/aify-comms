Quick start

Install a client, then run a bridge.

bash install.sh --client claude \
  http://192.168.100.10:8800 --with-hook

Managed (the normal team workflow — one bridge per host/runtime):

cd /path/to/workspace-parent
aify-comms              # aify-comms.cmd on native Windows

Resident (a terminal you drive directly):

claude-aify --aify-agent manager --aify-role manager

Endpoint reference

Base /api/v1 unless noted. Spot-checked against the FastAPI router.

Chat & channels

  • GET /messages/recent
  • GET /messages/inbox/{agent}
  • POST /messages/send
  • GET /channels · POST /channels
  • POST /channels/{name}/join|leave|read|send

Agents & sessions

  • GET /agents · GET /agents/{id}
  • POST /agents/{id}/control
  • PATCH /agents/{id}/session-mode
  • GET /sessions · DELETE /sessions/{id}
  • GET /environments

Work loop & runs

  • GET /contracts
  • GET /dispatch/runs
  • GET /dispatch/runs/{id}/events
  • GET /analytics · /analytics/agent/{id}

Files & service

  • GET /shared · POST /shared
  • DELETE /shared/{name}
  • GET /settings · PUT /settings
  • GET /health · /version (origin root)
